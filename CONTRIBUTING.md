# Contributing

Developed and maintained by [Synergetic Dev](https://synergetic.dev/). Use issues and pull requests for reproducible defects, documentation and compatible improvements.

Keep vendor plugin files untouched. Preserve explicit allowlists, gateway delegation, endpoint-bound tokens and encrypted personal identities. Never send credentials, customer exports or account data in an issue. Use owned disposable fixtures for writes.

Run `python tools/verify.py` and `python tools/build.py` locally, then the relevant WordPress fixture suite. Record actual environments and missing coverage. Original React build checks are unavailable; readable add-on components and generated seams are version-reviewed. See TESTING.md.

Update CHANGELOG.md with categorized operator-facing entries. Update docs and the Graphify map when behavior or relationships change. Do not hand-edit generated graph edges. Production activation and provider account changes require separate authorization.

No hosted workflows run automatically in this repository. Deliberate release publication uses the locally verified package and checksums.
